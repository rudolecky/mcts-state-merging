# Classical MCTS Merging on Three Men's Morris (No LLM)

## Question

Connect Four (irreversible, adversarial) gave a null: UCB1's untried-move bookkeeping already
prevents redundant exploration when moves never revisit a prior position. The 8-puzzle
(reversible, single-agent) gave a large positive effect: a single reversible token generates
massive redundant exploration under UCB1, which merging reclaims. Three Men's Morris fills the
remaining cell of that 2x2 -- **adversarial AND reversible**: placement is irreversible (like
Connect Four's drops), but the movement phase (sliding one of 3 own pieces to an adjacent empty
cell, forever) is exactly as reversible as the 8-puzzle. Does the effect show up here too?

## Setup

- `src/mcts_phase0/datasets/morris_engine.py`: 3x3 board, tic-tac-toe's 8 win-lines, king-move
  adjacency. `solve_forced_win`/`shortest_forced_win` mirror `connect_four_engine.py`'s
  alternating recursion exactly, over the movement-phase move generator. Puzzles generated by
  seeded rejection sampling over random 6-cell placements, filtered to an exact
  `shortest_forced_win == k_plies`.
- `src/mcts_phase0/classical_mcts_morris.py`: combines `classical_mcts.py`'s hero/opponent node
  shape with `classical_mcts_puzzle.py`'s cycle-safe `select()`/`run_search` (Morris's movement
  phase needed the same fix the 8-puzzle did -- confirmed by an explicit regression test that
  would have caught the exact plateau-regardless-of-budget bug found during that work; it passed
  cleanly on the first run here).
- Verified: `pytest tests/test_morris_engine.py tests/test_classical_mcts_morris.py` (25 tests)
  + full suite (200 passed) green.
- A real, checked structural detail: unlike the 8-puzzle (`k_plies` can go up to 31), Three Men's
  Morris's own forced-win depth has a hard practical ceiling. A distribution check over 16,245
  random placements found forced wins at 1 ply (7,720 occurrences), 3 plies (2,366), 5 plies
  (195), and **zero** at 7+ plies within a 9-ply search -- confirmed by a separate 200,000-attempt
  rejection-sampling run also finding zero. This is a real property of the game (small, drawish,
  similar to tic-tac-toe), not a search bug: default puzzle generation uses `k_plies=[1,3,5]`.

## Results

**Sweep 1** -- k_plies 1/3/5 (15 puzzles each), budgets 25-200, 50 repeats/condition:

| budget | overall diff | nodes base→treat |
|---|---|---|
| 25 | 0.000 | 26.0→26.0 |
| 50 | 0.000 | 51.0→49.8 |
| 100 | 0.000 | 100.8→91.3 |
| 200 | 0.000 | 195.6→163.4 |

By k_plies at budget=200: k=1, k=3, k=5 all reach baseline=treatment=1.000 (full ceiling).
Zero difference everywhere, `wilcoxon_p=nan` (all-zero diffs).

**Sweep 2** -- fine low-budget sweep (3-20) to rule out a pure ceiling artifact:

| budget | k=1 base/treat | k=3 base/treat | k=5 base/treat | nodes (all k) |
|---|---|---|---|---|
| 3 | 0.532 / 0.532 | 0.000 / 0.000 | 0.000 / 0.000 | 4.0→4.0 |
| 5 | 0.877 / 0.877 | 0.000 / 0.000 | 0.000 / 0.000 | 6.0→6.0 |
| 10 | 1.000 / 1.000 | 0.003 / 0.003 | 0.000 / 0.000 | 11.0→11.0 |
| 15 | 1.000 / 1.000 | 0.047 / 0.047 | 0.027 / 0.027 | 16.0→16.0 |
| 20 | 1.000 / 1.000 | 0.188 / 0.188 | 0.161 / 0.161 | 21.0→21.0 |

**This rules out a simple ceiling-effect explanation.** k=5 climbs cleanly off the floor
(0.000→0.027→0.161) across budgets 10-20, well below ceiling -- and the diff is still exactly
0.000 at every point, because node counts are **identical between conditions through budget=20**:
no merging has happened yet at all at these budgets. By budget=200, merging is real (195.6→163.4,
~16% reduction) but baseline has already saturated to 1.000 for every k_plies value by then. There
is no budget regime in this domain where both conditions hold at once -- substantial merging
*and* a baseline still meaningfully below ceiling.

## Mechanism

This is a genuine third finding, not a repeat of Connect Four's -- the *reason* for the null is
different, and it sharpens the project's central claim further. Reversibility alone was not
sufficient here, which the 8-puzzle result alone could not have shown.

The 8-puzzle's redundant-exploration density comes from a specific structural fact: there is
exactly **one** mobile element (the blank), so the entire state trajectory is a single continuous
random walk with a strong tendency to double back over recently-visited ground. Morris's movement
phase is reversible in the same local sense (undoing a slide returns the prior board), but the
state is now **jointly** determined by two independently-moving 3-piece sides, alternating turns.
Reaching the identical (board, to_move) pair via a different move order requires both players'
moves to compose to the same net configuration -- a real but much rarer coincidence than a single
token's random walk revisiting a cell (confirmed directly: node counts stayed byte-identical
between conditions through budget=20, and even by budget=200 reduction was only ~16%, versus the
8-puzzle's ~30-62% at comparable and lower budgets). Adversarial interleaving suppresses
redundant-exploration density even under reversible moves.

On top of that, Morris is intrinsically shallow (forced wins essentially don't exist past 5
plies), so baseline UCB1 solves it almost immediately regardless -- there's no room for a
budget-scaling story like the 8-puzzle's (where baseline stayed near-zero for hundreds of budget
units while treatment climbed to 1.000) to ever play out, because baseline saturates before
merging has accumulated enough volume to matter.

Combined with the other two results, the refined claim is: **merging helps in proportion to how
much redundant exploration of the same joint state the underlying search actually generates under
UCB1 -- and reversibility of individual moves is necessary but not sufficient for that.** A
single continuous mobile element (8-puzzle) generates it readily; multiple independently-acting,
adversarially-interleaved pieces (Morris) mostly don't, even though every individual move is
still perfectly reversible.

## Status

Closed. Two sweeps (budgets 3-200, spanning genuine floor-to-ceiling for every k_plies value),
a decisive null with node-count evidence ruling out both "it's just a ceiling artifact" and "no
merging is happening at all" as competing explanations. Mechanistically distinct from Connect
Four's null and directly informative about the limits of the 8-puzzle's positive result. Sokoban
is next per the standing plan (single-agent, mostly irreversible, deadlock states) -- a domain
picked specifically to test whether effect size is graded with redundant-exploration density
rather than a binary switch, which this result makes an even sharper question to ask.
